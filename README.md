# Machine Learning for Cybersecurity

A collection of projects exploring machine learning applications in cybersecurity, including intrusion detection, anomaly detection, and adversarial machine learning.

## Goal
To explore, implement, and evaluate machine learning techniques for cybersecurity, with a focus on adversarial machine learning and the security and robustness of ML models.

## Technologies

Python, Scikit-learn, Pandas, NumPy, and PyTorch.
